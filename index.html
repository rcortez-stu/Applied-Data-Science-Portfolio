Do Almond Trees Have Insomnia?

This project investigates whether winter chill accumulation and temperature patterns can be used to predict almond yield in Fresno County, California. Using NOAA weather data and USDA agricultural datasets, I cleaned and merged multiple data sources, performed exploratory data analysis, and built regression models to evaluate how winter conditions affect almond production.
